# Εξοδολόγιο

Αυτόνομη web εφαρμογή για κινητό που δημιουργεί το μηνιαίο εξοδολόγιο
(κάρτα καυσίμων / ΜΜΜ) ως PDF, με την απόδειξη στο πλαίσιο και την
υπογραφή σας, έτοιμο για αποστολή με email.

## Χρήση
1. Στις **Ρυθμίσεις αποστολής** ορίστε μία φορά email παραλήπτη, θέμα, εταιρεία και λογότυπο
   (ή ανοίξτε έναν «σύνδεσμο ρυθμίσεων» που σας έστειλε συνάδελφος).
2. Επιλέξτε μήνα (προεπιλογή: ο προηγούμενος) και ποσό.
3. Τραβήξτε φωτογραφία της απόδειξης ή επιλέξτε εικόνα / PDF.
4. Συμπληρώστε μία φορά τα στοιχεία σας και την υπογραφή.
5. Πατήστε **Αποστολή** → επιλέξτε την εφαρμογή email (το PDF είναι ήδη συνημμένο).

Όλα τα δεδομένα μένουν στη συσκευή — δεν υπάρχει server.

## Αρχείο χωρίς internet
`python3 build-single.py` → `Εξοδολόγιο.html`, ένα αυτόνομο αρχείο που ανοίγει απευθείας στον browser.
Προαιρετικά, ένα τοπικό `config.local.json` (δεν ανεβαίνει στο git) προσυμπληρώνει τις ρυθμίσεις:

```json
{ "email": "...", "subject": "εξοδολόγιο", "company": "...", "logo": "private/logo.jpg" }
```

Βιβλιοθήκες: jsPDF 2.5.1 (MIT), pdf.js 3.11.174 (Apache-2.0) στον φάκελο `vendor/`.
