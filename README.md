# Fuelpass

Web εφαρμογή για κινητό που συμπληρώνει ένα μηνιαίο έντυπο εξόδων (π.χ. κάρτα
καυσίμων / ΜΜΜ) πάνω στο δικό σας πρότυπο, με την απόδειξη και την υπογραφή σας,
και το στέλνει με email ως PDF.

## Χρήση
1. **Πρότυπο:** ανεβάστε το κενό έντυπο σε PDF ή φωτογραφία. Με το **📐 Θέσεις πεδίων**
   μετακινείτε τα πλαίσια (μήνας, στοιχεία, διαδρομή, ποσό, απόδειξη, υπογραφή) πάνω στο πρότυπο.
   Ό,τι υπάρχει ήδη μέσα σε ένα πλαίσιο στο πρότυπο καλύπτεται.
2. Επιλέξτε μήνα και ποσό, τραβήξτε φωτογραφία της απόδειξης ή επιλέξτε εικόνα / PDF.
3. Συμπληρώστε μία φορά τα στοιχεία σας και την υπογραφή.
4. Στο **⚙ Αποστολή email** ορίστε παραλήπτη και θέμα (ή ανοίξτε έναν «σύνδεσμο ρυθμίσεων»).
5. **📤 Αποστολή** → επιλέξτε την εφαρμογή email· το PDF είναι ήδη συνημμένο. **⬇ PDF** απλώς το αποθηκεύει.

Όλα τα δεδομένα μένουν στη συσκευή — δεν υπάρχει server. Μετά την πρώτη φόρτωση λειτουργεί και χωρίς internet.

Οδηγός χρήσης: `guide.html` (ανοίγει από το **❓ Βοήθεια** μέσα στην εφαρμογή) και `Fuelpass-Odigos.pdf`
(η ίδια σελίδα εκτυπωμένη σε PDF — μετά από αλλαγές στο `guide.html` εκτυπώστε την ξανά σε PDF).

Βιβλιοθήκες: jsPDF 2.5.1 (MIT), pdf.js 3.11.174 (Apache-2.0) στον φάκελο `vendor/`.
